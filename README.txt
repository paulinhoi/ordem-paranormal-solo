                    RESUMO DOS SISTEMAS
═══════════════════════════════════════════════════════════════

ATRIBUTOS (0-5):
• AGILIDADE - coordenação, velocidade
• FORÇA - potência muscular
• INTELECTO - raciocínio, define rituais
• PRESENÇA - sentidos, vontade, sociale
• VIGOR - saúde

PONTOS:
• PV (Pontos de Vida) - saúde física
• PE (Pontos de Esforço) - usar habilidades
• SAN (Sanidade) - saúde mental

NEX (%):
• 5% = início
• A cada missão bem-sucedida +5%
• Maior NEX = mais poder + mais risco de loucura

CLASSES:
• COMBATENTE: guerras, armas, resistência
• ESPECIALISTA: habilidades, social, tecnologia
• OCULTISTA: rituais, conhecimento paranormal

ELEMENTOS DO OUTRO LADO:
• SANGUE - emoção intensa
• MORTE - tempo
• CONHECIMENTO - consciência
• ENERGIA - caos
• MEDO - combustible para todos

MEMBRANA:
• INTACTA - impossível
• ESTÁVEL - segura
• DANIFICADA - normal
• ARRUINADA - muito perigoso
• ROMPIDA - catastrófico
